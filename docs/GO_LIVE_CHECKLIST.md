# ລາຍການກວດກ່ອນຂຶ້ນລະບົບຈິງ

ລາຍການເຫຼົ່ານີ້ເປັນງານມື ຫຼື ຕ້ອງໃຊ້ເຊີເວີຈິງ; ໂຄດບໍ່ໄດ້ເຮັດໃຫ້.

## 1. ສຳຮອງ ແລະ DNS (`xtklaos.com`)
- [ ] ສຳຮອງໜ້າເກົ່າ ແລະ ບັນທຶກ DNS ທັງໝົດກ່ອນປ່ຽນ.
- [ ] ປ່ຽນສະເພາະ record ຂອງເວັບ. **ຮັກສາ MX ໄວ້** ເພື່ອບໍ່ໃຫ້ອີເມວ @xtklaos.com ຂາດ.
- [ ] ໃນ 2 ບລັອກ Blogger: ໃສ່ JavaScript / meta redirect ແລະ ປ້າຍແຈ້ງຍ້າຍເວັບ ຊີ້ໄປໜ້າທີ່ກົງກັນ.
- [ ] ປ່ຽນລິ້ງເວັບໃນເພສ Facebook; ລົງທະບຽນ Google Search Console.

## 2. ຄ່າ env ໃນເຊີເວີຜະລິດ (ເບິ່ງ `web/.env.example`)
- [ ] `DATABASE_URL`, `AUTH_SECRET`, `NEXT_PUBLIC_SITE_URL` (ໂດເມນຈິງ, ໃຊ້ໃນລິ້ງໃນອີເມວ).
- [ ] `TELEGRAM_BOT_TOKEN` ແລະ `TELEGRAM_CHAT_ID_SALES / SERVICE / HR`.
- [ ] `SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASS, MAIL_FROM` (ທຸກຕົວຕ້ອງມີ ຈຶ່ງຈະສົ່ງອີເມວ).
- [ ] `CRON_SECRET` (`openssl rand -base64 32`).

## 3. ຕັ້ງ cron (ວັນລະເທື່ອ, ແນະນຳ 08:00 ເວລາລາວ)
```bash
curl -fsS -X POST -H "Authorization: Bearer $CRON_SECRET" https://<ໂດເມນ>/api/cron/reminders
```
ຕອບ `{"ok":true,"sent":N,...}`. ຕອບ 401 = secret ບໍ່ກົງ ຫຼື ບໍ່ໄດ້ຕັ້ງ.

## 4. ໄຟລ໌ອັບໂຫຼດ
- [ ] ຍ້າຍສະລິບ, QR ແລະ ໄຟລ໌ອື່ນຈາກດິສຝັງ (`web/storage`) ໄປ R2 / S3 ຜ່ານ `src/lib/storage.ts`.

## 5. ທົດສອບກັບຂອງຈິງ
- [ ] ມືຖື iOS / Android, ການສະແດງຜົນພາສາລາວ, ຄວາມໄວ.
- [ ] ລິ້ງ WhatsApp ດ້ວຍເບີ `8562055892929`.
- [ ] ສັ່ງຊື້ທົດລອງດ້ວຍອີເມວຈິງ: ໄດ້ຮັບອີເມວ "ຮັບຄຳສັ່ງຊື້", ແລ້ວຢືນຢັນຊຳລະ ແລະ ກວດວ່າໄດ້ອີເມວຕໍ່.
- [ ] ເອີ້ນ cron ດ້ວຍມື ແລະ ກວດວ່າຂໍ້ຄວາມເຂົ້າ Telegram; ເອີ້ນຊ້ຳ ຕ້ອງບໍ່ໄດ້ຂໍ້ຄວາມຊ້ຳ.

## 6. ຂໍ້ມູນທຸລະກິດກ່ອນເປີດຂາຍອອນລາຍ
